# Harshita Dutt — Anti-Gravity Portfolio & Future Systems // 2026

A minimalist, heroic, futuristic personal portfolio website inspired by **anti-gravity technology, advanced aerospace, artificial intelligence, and the frontier of engineering**.

Built with an **Apple × SpaceX × Futuristic Research Laboratory** aesthetic.

---

## ✨ Features

- **Anti-Gravity Physics Field (`canvas.js`)**: Interactive 60fps HTML5 Canvas simulation with buoyant floating particles, rotating orbital trajectory rings, and mouse disturbance fields.
- **Live GitHub Integration (`github.js`)**: Real-time REST API integration connected directly to GitHub (`harshitadutt100-ship-it`). Automatically displays latest repositories, star counts, topics, and programming languages with local caching and offline fallback.
- **Curated Flagships & Dual-Tab System**: Toggle smoothly between visionary flagship concepts (*Project Nova*, *Orbit*, *Zero-G*) and verified live GitHub repositories (*E-Commerce Platform*, *Netflix Dashboard*, *MySQL Architecture*, *Testing Suite*).
- **Interactive Sound Architecture (Web Audio API)**: Self-contained sci-fi interface audio synthesis for button hovers and click feedback, with an audio toggle. Zero external MP3/WAV dependencies.
- **Interactive 3D Depth**: Dynamic perspective tilt on cards tracking cursor coordinates.
- **Centralized Configuration (`config.js`)**: Update your name, roles, portrait, telemetry, education, capabilities, and social links in seconds without editing HTML or CSS.
- **Responsive & Accessible**: Optimized for mobile, tablet, laptop, and ultra-wide displays.

## 🚀 Quick Start (Local Preview)

### Option 1: Using Python's Built-in Server (Recommended)
From the project folder, run:
```bash
python -m http.server 8080
```
Then open your browser and navigate to:
```text
http://localhost:8080
```

### Option 2: Direct File Open
You can simply double-click `index.html` to open the website directly in Chrome, Edge, Safari, or Firefox.

---

## ⚙️ Customization (`config.js`)

All content is driven by `config.js`. Open `config.js` to modify:
- **`profile`**: Your name, headline, email, GitHub username, LinkedIn URL, and portrait image.
- **`flagshipProjects`**: Custom flagship technology projects with tags, descriptions, and URLs.
- **`education`**: Your degrees, institutions, graduation dates, and achievements.
- **`capabilities`**: Skills and disciplines displayed in the floating anti-gravity cloud.
- **`philosophy`**: Your personal vision statement.

## 🌐 Deploying to GitHub Pages

To host your portfolio for free on your GitHub domain (`https://harshitadutt100-ship-it.github.io`):

1. Initialize git in this directory:
   ```bash
   cd C:\Users\Pankaj\.gemini\antigravity\scratch\anti-gravity-portfolio
   git init
   git add .
   git commit -m "Initialize anti-gravity futuristic portfolio"
   ```

2. Create a new repository on your GitHub named `harshitadutt100-ship-it.github.io` (or `portfolio`).

3. Link and push your repository:
   ```bash
   git branch -M main
   git remote add origin https://github.com/harshitadutt100-ship-it/portfolio.git
   git push -u origin main
   ```

4. Go to **Repository Settings** → **Pages** → select `main` branch → **Save**.
Your futuristic website is now live on the web!
